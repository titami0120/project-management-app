# 計画工数CSV仕様

## 基本仕様

| 項目 | 仕様 |
|------|------|
| ファイル形式 | CSV（カンマ区切り） |
| 文字コード | Shift-JIS（固定） |
| 改行コード | CRLF |
| ヘッダー行 | 1行目（列名行） |
| データ行 | 2行目以降 |
| 拡張子 | .csv |

## 会計年度 → 年月 変換ルール

CSV の1行に会計年度（FY）と12ヶ月分の工数が含まれる。  
DBの `monthly_workloads.year` / `month` へは下表のルールで変換する。

| CSV列名 | year | month |
|---------|:----:|:-----:|
| 4月 | FY | 4 |
| 5月 | FY | 5 |
| 6月 | FY | 6 |
| 7月 | FY | 7 |
| 8月 | FY | 8 |
| 9月 | FY | 9 |
| 10月 | FY | 10 |
| 11月 | FY | 11 |
| 12月 | FY | 12 |
| 1月 | FY + 1 | 1 |
| 2月 | FY + 1 | 2 |
| 3月 | FY + 1 | 3 |

**例** — 会計年度 = 2026 の場合:

```
4月  → year=2026, month=4
12月 → year=2026, month=12
1月  → year=2027, month=1
3月  → year=2027, month=3
```

## 処理仕様

### フェーズ 1: バリデーション

全行を走査してエラーを収集し、一括返却する。エラーが1件でもあればフェーズ 2（DB操作）には進まない。

#### ヘッダー検証（行番号なし）

| チェック | エラー条件 | エラーメッセージ |
|---------|-----------|---------------|
| 必須列の存在確認 | `所属部門コード`・`所属部門名`・`社員コード`・`氏名`・`WBS仮コード`・`WBS名称`・`会計年度`・`4月`〜`3月`（12列）のいずれかが存在しない | `列"{列名}"が見つかりません` |

#### 行バリデーション（全行を走査して収集）

| 列名 | チェック | エラー条件 | エラーメッセージ例 |
|------|---------|-----------|----------------|
| 所属部門コード | 空白チェック | 空文字またはスペースのみ | `所属部門コードは空にできません` |
| 所属部門名 | 空白チェック | 空文字またはスペースのみ | `所属部門名は空にできません` |
| 社員コード | 空白チェック | 空文字またはスペースのみ | `社員コードは空にできません` |
| 氏名 | 空白チェック | 空文字またはスペースのみ | `氏名は空にできません` |
| WBS仮コード | 空白チェック | 空文字またはスペースのみ | `WBS仮コードは空にできません` |
| WBS名称 | 空白チェック | 空文字またはスペースのみ | `WBS名称は空にできません` |
| 会計年度 | 整数・範囲チェック | 整数変換不可 または 1900〜2100 の範囲外 | `会計年度の値が不正です: '{値}'（整数で1900〜2100の範囲を指定してください）` |
| 4月〜3月（各列） | 数値・符号チェック | 数値変換不可 または 0 未満 | `{月}の値が不正です: '{値}'（0以上の数値を指定してください）` |

---

### フェーズ 2: DB操作（全バリデーションOK後）

1トランザクション内でFK依存順序に従って処理する。エラーが発生した場合は全件ロールバック。

#### 2-1. 部門 upsert（`departments.code` をキーとして）

| 条件 | 処理 |
|------|------|
| `所属部門コード` がDBに存在しない | `code`・`name` で新規 INSERT |
| `所属部門コード` がDBに既存する | `name` を CSV の最新値で UPDATE（`is_deleted` は変更しない） |

#### 2-2. 要員 upsert（`members.employee_code` をキーとして）

| 条件 | 処理 |
|------|------|
| `社員コード` がDBに存在しない | `employee_code`・`name`・`department_id`（所属部門コードで解決）で新規 INSERT |
| `社員コード` がDBに既存する | `name`・`department_id` を CSV の最新値で UPDATE（`is_deleted` は変更しない） |

#### 2-3. プロジェクト upsert（`projects.wbs_tmp` をキーとして）

| 条件 | 処理 |
|------|------|
| `WBS仮コード` がDBに存在しない | `wbs_tmp`・`name`・`matter_id=NULL` で新規 INSERT。`WBSコード` 列が存在し値が空でない場合は `code` も設定 |
| `WBS仮コード` がDBに既存する | `name` を UPDATE。`WBSコード` 列が存在し値が空でない場合は `code` も UPDATE（`is_deleted` は変更しない） |

> `WBSコード` と `WBS仮コード` が同値のケースは正常（エラーにしない）

#### 2-4. 月次工数 upsert（`(member_id, project_id, year, month)` をキーとして）

CSV の1行から会計年度変換ルールに基づき最大12件の月次工数を処理する。

| DBレコードの有無 | 月の工数値 | 処理 |
|----------------|-----------|------|
| 存在しない | > 0.00 | `member_id`・`project_id`・`year`・`month`・`planned_mm` で新規 INSERT |
| 存在しない | = 0.00 | **スキップ**（INSERT しない） |
| 存在する | 任意の値（0.00 を含む） | `planned_mm` を CSV の値で UPDATE（`simulated_mm`・`actual_mm` は変更しない） |

> **全月が 0.00 の行でも**、部門・要員・プロジェクトのマスタ upsert（2-1〜2-3）は実施する

#### 2-5. 見込工数バージョン作成（`forecast_versions`）

`trigger_type = 'plan_upload'` で新規 INSERT。バージョン番号は `MAX(version_no) + 1` で自動採番。

#### 2-6. スナップショット作成（`forecast_snapshots`）

全 `monthly_workloads` から `COALESCE(simulated_mm, planned_mm)` を計算し、値が NOT NULL のレコードをすべて INSERT。

## エラー応答フォーマット

**HTTP 422 レスポンス（バリデーションエラー時）**

```json
{
  "errors": [
    {
      "row_no": null,
      "column": "4月",
      "message": "列\"4月\"が見つかりません"
    },
    {
      "row_no": 3,
      "column": "会計年度",
      "message": "会計年度の値が不正です: 'abc'（整数で1900〜2100の範囲を指定してください）"
    },
    {
      "row_no": 7,
      "column": "8月",
      "message": "8月の値が不正です: '-0.50'（0以上の数値を指定してください）"
    }
  ]
}
```

> ヘッダーエラーは `row_no: null`。行バリデーションエラーは `row_no` に2行目以降の行番号（1始まり）を格納する

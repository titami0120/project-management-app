# UI・UXルール

## 基本方針
- **言語**：日本語のみ。ラベル・エラーメッセージ・プレースホルダー・通知メッセージはすべて日本語で記述する
- **UIライブラリ**：Ant Design 5.x を中心に使用する
- **独自スタイルの上書きは最小限**に留め、Ant Design のデザイントークン（ConfigProvider）で対応する
- コンポーネントライブラリにないUI要素が必要な場合のみ、Tailwind CSS またはインラインスタイルで対応する

---

## 主要UIパターン

### テーブル表示
- 一覧表示は Ant Design の `<Table>` コンポーネントを使用する
- ソート・フィルタ機能は Ant Design の組み込み機能（`sorter`・`filters`）を活用する
- ページネーションはデフォルトで有効化する
- 空状態のメッセージは `locale.emptyText` で日本語に設定する（例：「データがありません」）

### フォーム
- フォームは `<Form>` + `<Form.Item>` で統一する
- バリデーションエラーはフィールド下部にインライン表示する（`validateStatus` + `help`）
- 必須項目には `required` マーカーを表示する

### 通知・警告・確認

| ケース | UIパターン |
|--------|-----------|
| 月次見込工数合計が1.0人月超 | `notification.warning`（処理はブロックしない。保存は許容する） |
| CSVアップロード成功 | `notification.success`（バージョン番号を含めてメッセージ表示） |
| CSVアップロード失敗・バリデーションエラー | `notification.error`（エラー行・理由を表示する） |
| 操作成功 | `notification.success` |
| エラー | `notification.error` |
| 削除など不可逆な操作の前 | `Modal.confirm` で確認ダイアログを表示する |

### CSVアップロード
- ドラッグ&ドロップとファイル選択の両方に対応する（Ant Design の `<Upload>` コンポーネント）
- アップロード中はプログレス表示、完了後に取り込み件数と作成バージョン番号を表示する
- バリデーションエラーは行番号・列名・エラー内容を一覧で表示する

### CSVダウンロード
- Ant Design の `<Button>` にアイコンを付け、クリックでダウンロード開始する
- ファイル名には対象年月またはバージョン番号を含める（例：`simulation_2025-06.csv`）

### レイアウト
- サイドバーナビゲーション + コンテンツエリアの2カラムレイアウトを基本とする
- Ant Design の `<Layout>` + `<Sider>` + `<Content>` を使用する
- コンテンツエリアはセクションごとに `<Card>` でまとめる

### ナビゲーション構成（サイドバー）

```
├─ 見込工数確認・シミュレーション
├─ 今月見込みCSVとの比較
├─ 案件・プロジェクト
│   ├─ 案件一覧（配下プロジェクトの工数サマリを表示）
│   └─ プロジェクト管理（案件配下のプロジェクト登録・編集）
├─ 要員
│   ├─ 要員一覧
│   └─ 要員登録
├─ 組織
│   ├─ 部門管理
│   └─ チーム管理
└─ アップロード
    ├─ 計画工数CSVアップロード
    └─ 実績工数CSVアップロード
```

## UX注意事項
- クリック可能な要素には hover 時のフィードバック（色変化・カーソル変化）を必ず付ける
- ローディング状態は `<Spin>` または `<Table loading={true}>` で表示する
- データの保存・削除は楽観的UIではなく、APIの完了後に画面を更新する
- 工数（人月）の入力値は小数点第2位まで許容する（例：0.50人月）
